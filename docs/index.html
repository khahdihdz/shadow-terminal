TRẢI NGHIỆM

Một thế giới bí ẩn ngay trong Terminal

⚔️ Chiến đấu theo lượt

Đối đầu kẻ địch, sử dụng kỹ năng, vật phẩm, phòng thủ hoặc tìm cách bỏ chạy.

🗺️ Khám phá

Di chuyển qua 6 khu vực, gặp sự kiện ngẫu nhiên và tìm tài nguyên.

🔎 Điều tra

Thu thập manh mối, đọc hồ sơ, đối chiếu dữ kiện và giải các vụ án mô phỏng.

📦 Save trong Downloads

Dữ liệu được lưu tại Download/ShadowTerminal/, thuận tiện sao lưu trên Android.

📈 Phát triển nhân vật

Lên cấp, nhận điểm kỹ năng, tăng sức mạnh, phòng thủ, trí tuệ và may mắn.

🛡️ OSINT an toàn

Các tình huống điều tra chỉ dùng dữ liệu hư cấu, không quét mạng hay thu thập dữ liệu thật.

Tín hiệu Night Raven

BẮT ĐẦU

Cài đặt nhanh trên Termux

pkg update
pkg install python git
termux-setup-storage

git clone https://github.com/khahdihdz/shadow-terminal.git
cd shadow-terminal
bash install.sh
shadow

Sau khi cài, lệnh shadow được đặt trong thư mục lệnh của Termux.
